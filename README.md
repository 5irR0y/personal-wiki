# Personal Wiki

Leroy's life / non-work knowledge base: personal to-dos, trips and plans, media watch history, and
career material (resume, work history, notes about career moves). It is a standalone repo and does
not depend on the work wiki.

Clone it anywhere and open it in Claude Code or Cursor. `CLAUDE.md` loads the operating rules.

## How to use

- Drop raw files into `Personal Inbox/`, or tell the AI in chat. The AI files the content and empties the inbox.
- Prefer markdown. Filing rules: `ai-guidance/repository-rules.md`.

## Folders

| Folder | Purpose |
| --- | --- |
| `Personal Inbox/` | Drop zone for personal files; the AI files them and empties it |
| `todos/` | Life to-dos and archive ([conventions](todos/README.md)) |
| `projects/` | Active life projects (trips, plans, career search) |
| `projects/archive/` | Closed life projects, kept as reference for next time |
| `reference/` | Standing reference notes ([important dates](reference/important-dates.md)) |
| `media/` | Movie / TV watch history ([media/README.md](media/README.md)) |
| `ai-guidance/` | Rules for AI when operating on this wiki |
| `.cursor/rules/` | Cursor always-apply rules |

Add subfolders (`people/`, `reference/`, …) when content warrants them.

## To-do files

| File | Use |
| --- | --- |
| [todos/open.md](todos/open.md) | Open one-time items, recurring definitions, active recurring |
| [todos/archive.md](todos/archive.md) | Completed items (with done date) |

Ids: historical items keep `P-###`; new items use `Pers-###`.

## Work-adjacent content that belongs here

Resume, work history, and career-search material live here (see `projects/phoenix.md`). Notes about
co-workers that matter to a career search or personal life may live here too. Day-to-day work
records and the company contact directory stay in the separate work wiki (`personal-work-wiki`).
